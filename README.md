# ☕ Java Programming Journey — From Zero to Advanced 🚀

Welcome to my **Java Learning Repository** 👋  
This repository documents my **step-by-step journey** of learning **Core Java**, starting from **absolute zero** and gradually moving to **advanced concepts**.

The goal is **not just to learn syntax**, but to:
- 🧠 Build **strong coding logic**
- 💪 Gain **confidence**
- 🎯 Prepare effectively for **interviews**

---

## 🎯 Learning Philosophy

This journey follows a **structured, syllabus-like approach**:

- Start from the **ground level**
- Move forward **only after mastering the current level**
- Focus on **logic + clarity**, not shortcuts
- Write **clean, readable Java programs**

> 💡 *If the basics are strong, advanced concepts become easy.*

---

**Strict Rules at this level:**
- ❌ No OOPS

- ❌ No advanced syntax
